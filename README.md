# İSG Mevzuat ve Kurum Hafızası Arşivi

Sağlık tesisleri odaklı İSG yapay zeka asistanı için yapılandırılmış bilgi kaynağı.

## Dizin Yapısı
- `01-kanunlar/`: Temel kanun metinleri ve ekleri
- `02-temel-yonetmelikler/`: Genel İSG yönetmelikleri
- `03-saglik-ozel-yonetmelikler/`: Sağlık tesislerine özel yönetmelikler
- `04-sks-ve-kurum-talimatlari/`: SKS standartları ve kurum içi prosedürler
- `05-kurum-hafizasi-arsivi/`: Canlı saha tespitlerinden damıtılan anonim tecrübe kartları
